## 1.2.0 — unified release (2026-11-26)

Unified version across CLI and desktop; this tag is `desktop-v1.2.0` for the desktop
builds and `v1.2.0` for the CLI, so neither takes the other's release slot.

## What's new

### Desktop

- Unified release number with the CLI (0.3.37 → 1.2.0).
- Release tooling bugfixes: version script now reads the `pantheon-desktop` package
  name from `src-tauri/Cargo.toml` and bumps `Cargo.lock` correctly, and the in-app
  updater manifest now points signed assets at the correct `desktop-vX.Y.Z` release
  path instead of `vX.Y.Z` (previously 404'd).

## Assets

- Pantheon-Linux-x86_64.AppImage (sha256 + `name.sha256` signature beside it)
- Pantheon-Linux-aarch64.AppImage
- Pantheon-macOS-x64.app.tar.gz
- Pantheon-macOS-arm64.app.tar.gz
- Pantheon-Windows-x64-setup.exe

## Signing

- CLI assets carry minisign signatures and `pantheon update` verifies them against the pinned key; see `docs/release-signing.md`. Desktop updater assets use the separate Tauri updater key already set in `tauri.conf.json`.
