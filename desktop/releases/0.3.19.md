# Control your other computers

## Remote access

- **PandaCode Connect lets one PandaCode drive another.** Sign in with GitHub in Settings → Remote access on each computer. Turn on **Allow remote control of this computer** on the one you want to drive, and mark the computers **Trusted** on each other after comparing their fingerprints. Your other computers then appear under **Computers** in the sidebar. From there you can read their tasks as they stream, send messages, start new tasks, stop runs and answer approvals.
- **It's off until you sign in.** Nothing is sent anywhere before that. After sign-in, PandaCode keeps one connection to the PandaCode relay, which runs on Cloudflare. Messages between your computers are encrypted end to end (X25519 and XChaCha20-Poly1305), so the relay forwards only ciphertext and stores no task content. Remote prompts follow the approval settings of the computer they run on.
- **It's free,** with up to 10 computers per account.

## Known limitations

- Remote access was tested with automated tests only; it has not been tried between two real computers yet.
- A computer must stay awake and online to be controlled. One that sleeps shows as offline within about 75 seconds.
- Very long transcripts load in pages, and a single message over 120 KB is shortened in the remote view.
