# No Keychain prompts

## Fixes

- **Pantheon no longer asks for your Keychain password after updates.** macOS tied every key Pantheon saved (bot channels, cloud sandboxes, provider API keys, connections) to the exact build that saved it, so each update asked for your login password again. On macOS these keys now live in one private file in Pantheon's data folder that only your user account can read, the same way remote access has since 0.3.29.
- **Your saved keys come along.** Each key still in the Keychain is moved over the first time Pantheon needs it, then removed from the Keychain. macOS may ask one last time per key while it moves; after that it never asks again.

## Known limitations

- Windows and Linux are unchanged: they keep using Credential Manager and Secret Service, which never had this problem.
