# Muse Code

## New

- **Muse Code is a harness.** PandaCode runs Meta's `muse serve` and talks to it over MSP, Muse's own session protocol. Text, reasoning and tool activity stream as Muse works. Follow-ups continue the same Muse session with PandaCode's tools still attached. Approvals and questions, including multi-select, open in PandaCode. You can steer mid-turn, stop, attach images, pick a model and reasoning effort, and run Muse skills from the `/` menu. Standard, Accept edits, Plan and Full access map onto Muse's approval modes and sandbox. Sign in once with `muse login` (#94).

## Known limitations

- Muse reviews tool calls with its own AI judge before PandaCode sees them and approves the ones it considers safe; `muse serve` cannot turn this off, so Standard and Accept edits only ask about calls it escalates or that leave the sandbox.
- Muse has no plan mode. PandaCode's Plan runs it read-only (no file writes or shell) with a planning instruction.
- Agent usage shows no usage limits for Muse, and subagent transcripts, goals, workflows and `/compact` are not available for Muse yet.
