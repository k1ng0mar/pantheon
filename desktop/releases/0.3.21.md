# Oh My Pi, Command Code and a better GitHub view

## New agents

- **Command Code.** Run Command Code as an agent through its ACP server. Its models, effort levels and slash commands appear in PandaCode, and Standard, Accept edits, Plan and Full access use Command Code's own permission modes. You can save an API key in the system keychain, or sign in with `command-code login`. Thanks @ktappdev (#56).
- **Oh My Pi (omp).** Run omp, the Pi fork, as an agent. It uses your existing omp login and setup.

## Teams

- **Lead guidance.** Team setup can carry your own rules for the team lead, for example "only coordinate, never edit files". They're added after the built-in rules. Reset to default clears them. Thanks @ktappdev (#61).
- **Effort for each role.** In Settings → Agent teams you can set the lead's effort separately from the workers'. For example, the lead can run at High while the workers run at Medium.

## GitHub view

- **Actions make sense next to pull requests.** Each run shows its event, its pull request, how many attempts it took and how long it ran. You can filter runs by event or pull request, or keep only the latest run per pull request. Each pull request has a **Runs** link to its runs.
- **Run details.** Expanding a run shows its jobs with their durations, and its artifacts with their sizes.
- **Workflows that never started.** A run GitHub couldn't start, for example because of an invalid workflow file or a missing runner, now reads "Didn't start". Its **Fix** action asks the agent to check the workflow file.
- **Typing is no longer erased.** Text you type in the GitHub view now stays when the view refreshes.

## Everywhere else

- **Remove a project.** Settings → General → Projects lists your projects and can remove one, including one whose folder was deleted. The project's tasks are removed from PandaCode; the folder stays on disk.
- **Drag the window by its header again on macOS.**
- **Links open in your browser.** Links in Markdown, provider cards and the quick launcher now open in your default browser. Thanks @jojomensah89 (#40).
- **File icons.** The Files tab, the `@` menu and changed-file lists show Material Icon Theme icons. They load the first time they're needed, not at startup. Thanks @SakithaSamarathunga33 (#49).
- **Task timers and defaults.** Working tasks show how long they've been running. Settings has a default model for new tasks and an **Expand tool activity** option for past turns; a running turn's activity always stays open. Thanks @ExcuseMeBro (#37).
- **Linux arm64.** A native `PandaCode-Linux-aarch64.AppImage` is published with automatic updates, and `npx pandacode` installs it.
- **Android emulators on Windows.** The Simulators tab lists Android devices on Windows. Without an SDK, it explains how to install one.

## Fixes

- **Agents work again from the Linux AppImage.** The AppImage's own library and Python paths no longer reach agents, terminals or git. These had broken `/usr/bin/env` ("version `LIBSYSTEMD_254' not found"), `curl` and `python3` in agent shells.
- **Grok Build is found in `~/.grok/bin`,** where its official installer puts it.
- **A warm Claude agent that isn't reused is now logged with the reason,** to help track down slow follow-up turns.

## Known limitations

- The Linux arm64 build and the Windows Android support have not been tested on real machines yet.
- Oh My Pi has been tested against recorded messages only, not a live install. Run omp with Bun, as its installer sets up.
- Command Code can't be steered mid-turn: messages you send during a turn are queued.
