# Cline, and steering that never stops the run

## New

- **Cline is a harness.** PandaCode runs `cline --acp` and lists Cline's models from your account without sending a prompt. Reasoning effort, Plan, Accept edits and Full access all work, and follow-ups continue the same Cline session. Sign in once with `cline auth` (or set `CLINE_API_KEY`) (#93).
- **Steer without stopping.** Every harness now takes a steer mid-run: Claude Code and Codex steer the live turn, OpenCode takes a second prompt, and the other ACP harnesses send it the moment the current turn ends, in the same run. A Steer button sits beside Stop (⌘/Ctrl↩ still works), the pending message shows whether it is steering now or sends at turn end, and a failed steer returns to the queue (#92).

## Known limitations

- Cline 3.0.73 accepts only text in prompts, so attached images are passed as file paths for Cline to open. It does not use PandaCode's tools (automatic titles, Run/preview, team tools), and it has no slash commands, context usage or usage limits in PandaCode.
- A steer that is saved, later fails and is resent can appear twice in the history.
