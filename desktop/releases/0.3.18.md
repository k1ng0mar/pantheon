# Install with one command

## Installing

- **`npx pandacode` installs PandaCode.** It downloads the latest release from GitHub, checks it against PandaCode's update signing key before installing anything, and installs the right build: macOS Apple silicon into Applications, Windows x64 with a silent install, Linux x64 as an AppImage in `~/.local/bin` with a menu entry. `npx pandacode --dry-run` downloads and verifies without installing.

## macOS

- **PandaCode signs itself on your Mac.** The app is signed with a certificate created once on your machine and kept in its own keychain, without any prompt. It happens on install, at startup and after every automatic update, so keychain access and privacy permissions now survive updates instead of being asked for again.

## Known limitations

- The first local signing changes the app's identity once, so macOS may ask one more time for keychain access to secrets PandaCode saved before.
- Local signing does not satisfy Gatekeeper; installs through `npx` avoid the first-launch warning because the download is not quarantined.
- The Windows and Linux `npx` installs have not been tried on real machines yet.
