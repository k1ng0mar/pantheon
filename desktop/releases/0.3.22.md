# Stay signed in, pick models that exist

## Remote access

- **PandaCode Connect stays signed in across updates.** Updating no longer asks you to sign in again. If 0.3.20 or 0.3.21 signed you out, 0.3.22 picks up your earlier sign-in by itself, as the same computer, so the computers you trusted stay trusted. A brief Keychain hiccup right after an update is retried quietly instead of signing you out, and your sign-in renews itself before it expires.
- **The model picker shows what the other computer has.** For a task that runs on another computer, the picker lists only the providers and models installed there. If your current model isn't on the computer you pick, PandaCode switches to one that is and tells you; picking This computer again brings your choice back.

## Known limitations

- If the earlier sign-in can't be found (for example it was removed from Keychain), sign in once more in Settings → Remote access.
- Remote access is covered by automated tests; it has not been tried between two real computers yet.
