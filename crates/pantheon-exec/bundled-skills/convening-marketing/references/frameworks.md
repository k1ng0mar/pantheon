# Strategy Frameworks (Phase 2)

Load during Phase 2. These are tools, not rituals: the Strategist uses what the evidence supports and says what it rejected.

## STP (Segmentation, Targeting, Positioning)

1. **Segment** the consumer base using the Consumer Researcher's profiles (behavior-based, not demographic cliches).
2. **Score** each segment on: counted size, reachability (where they gather, and whether a small team can access it), value (willingness-to-pay evidence), and product fit.
3. **Target**: ONE primary segment (the strategy must lose the runner-up explicitly: name it and why it lost).
4. **Position** only for that primary segment first.

## Positioning (built from evidence, not adjectives)

Following the value-based approach (build the value prop from positioning, not features):

1. Name the **competitive alternatives** (what the target customer genuinely uses today, including "nothing" and spreadsheets/WhatsApp if that is the real alternative).
2. Name the **unique strengths** the product has that those alternatives lack (from the Product Expert's map, verified vs. the Competitive Analyst's teardown).
3. Find the **value** those strengths unlock for the primary segment (from the Consumer Researcher's behavior evidence).
4. Identify the **market category** to compete in (the frame that makes the strengths matter).
5. Write the positioning statement: For [target], who [pain/JTBD], [product] is the [category] that [unique value], unlike [alternative], because [strength]. Every slot must be backed by a finding, not a thesaurus.
6. Distill a one-liner and 3-5 message pillars. Objections must come from real customer language found in research.

## Pricing direction

Anchor against real competitor prices and observed willingness-to-pay in the market (see competitive teardown). Consider: freemium only if usage spreads the word; tiering only if segments genuinely differ; undercutting only if cost-advantaged; premium only with a differentiated or service moat. State the assumption behind every number.

## Channel selection

For each candidate channel: does the counted primary segment demonstrably spend time there (cite where), estimated acquisition cost vs. value, and feasibility for the actual team size/budget. Rank and cut.

## KPI system

- **North-star metric**: one metric that captures delivered value + growth.
- **Funnel metrics per channel**: reach to engagement to conversion to revenue, with per-channel depth (e.g., organic: rankings/traffic for SEO; paid: ROAS/CPC; email: open/CTR/click-to-revenue; social: engagement-to-conversion).
- **Efficiency metrics**: CAC, and CAC:LTV ratio; content: cost per qualified lead; brand (if measurable at all): direct search volume trend.
- **Targets**: starting targets from category benchmarks found in research, marked `[ESTIMATE]` when no benchmark exists. Review cadence: weekly for tactics, monthly for strategy. Define kill criteria in advance.
