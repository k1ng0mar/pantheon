## When to Use

Use before writing prose, UI copy, or any design deliverable for Umar. Use when reviewing a page, a screenshot, or a component. This is a rejection checklist, not a style guide.

# AI slop tells

Umar sent this list as habits that mark generated work. Apply it before shipping prose, UI, or a screenshot. Apply it silently.

Use `anti-ai-writing` for sentence level rules. This skill covers visible tells in copy and interface.

## Buttons and layout

- arrow icons on every button
- card layouts for everything
- repeated three-item icon rows

## Typography and headings

- one slanted word in a headline
- a popular serif used as default
- short two-word sentences

## Decoration

- small dots between words
- sparkle icons
- soft glow behind the hero
- coloured side borders
- grainy texture effect

## Colour and labels

- pale cream backgrounds
- pill labels above headlines
- small eyebrow text everywhere

## Copy and claims

- buzzwords about quietness and realness
- invented statistics

## Motion and structure

- sections that fade in on scroll
- numbered sections
- pulsing green status dots

## From earlier corrections

- a subtitle with an em dash sitting right above it
- multicoloured hero text
- a random pointer with a blowing dot
- numbered lists used as default structure

## Use

Check each section you write or build. If a tell is present, remove it or defend it in one line. Do not add a tell while fixing another.

Umar called this a 20 point list. The list he sent contains 19 items.
