# Verification loop

A screen does not exist until you have seen it running.

1. Implement, launch in browser/simulator/emulator
2. Screenshot and actually look: alignment, spacing, truncation, dark mode
3. Run the full-motion pass: screen-record the entire flow
4. Fix, relaunch, re-verify. Repeat until you cannot find a defect.

Do not declare a screen finished from code review alone.
