Install

Two commands. One minute.

Install Pantheon:

curl -fsSL https://raw.githubusercontent.com/k1ng0mar/pantheon/master/install.sh | bash
iwr https://raw.githubusercontent.com/k1ng0mar/pantheon/master/install.ps1 -useb | iex 
git clone https://github.com/k1ng0mar/pantheon.git
cd pantheon
cargo build --release

Configure your provider:

pantheon setup

Then start Pantheon:

pantheon

That is it. Pantheon handles the runtime, state, tools, memory, and everything around the model.

Something not working? See troubleshooting, or read the getting started guide.
